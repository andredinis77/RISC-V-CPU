# RISC-V-CPU
I designed a simple RISC-V CPU. It holds operations all operations from RV32I Base Integer Instructions, but doesn't have pipeline implemented.
For the testbench I created, I used a text file with the supposed values that the cpu had to give.
The assembly code was extracted using an application called RARS, where I created de assembly code and then extracted to the machine code.
You can see this assembly code at instruction memory module code.
