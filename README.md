# RISC-V-CPU
I designed a simple RISC-V CPU. It supports all operations from RV32I Base Integer Instructions, but doesn't have pipeline implemented.

For the testbench I created, I used a text file with the supposed output values from cpu.

The machine code from assembly code was extracted by the software RARS, where I created the assembly code and then extracted to the machine code.
You can see this assembly code at instruction memory module code.
